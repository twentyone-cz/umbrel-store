# jednadvacet — Umbrel community app store

Community app store pro umbrelOS. Přidání: v Umbrelu *App Store* → menu (⋮)
→ **Community App Stores** → vlož

```
https://github.com/twentyone-cz/umbrel-store
```

## Appky

- **jednadvacet phone** — vlastní telefonní brána: hovory a SMS z tvé SIM
  karty kamkoli, přes privátní šifrovanou síť. Web produktu a návod:
  <https://phone.twentyone.cz>
